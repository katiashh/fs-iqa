# Original supplementary code

`demo_code_fs_iqa_dbcnn.py` is an unchanged copy of the script supplied with the
paper. It is retained for provenance and comparison, not used by the cleaned
CLI or imported by tests. The file needs external weights and data and contains
the implementation issues documented in [IMPLEMENTATION.md](../docs/IMPLEMENTATION.md).

Use `python -m fs_iqa.cli --help` from the repository root for the cleaned entry
point. The archived CSV in `results/` is also preserved without modification.
